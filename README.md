# Portfolio: Zain Ul Abideen

Personal portfolio for a web, app and AI developer. Light editorial design: a huge outlined name with a cutout portrait (greyscale, with a colour reveal under the cursor), a scroll-lit statement, a filterable work grid with full-screen case studies (shareable `#work/<id>` links), expanding service rows, a dark skills block and a centred contact section.

**Projects shown:** Lumen Stay · Glow Studio (web) · MindAI (app) · Aria · Zarri · CorpMind (AI)

## Edit your details

Everything personal is in `src/data.ts`: name, role, pitch, email, WhatsApp, LinkedIn, GitHub, the projects, services and skills. Screenshots live in `public/work/` as `<name>-1280/1920` (desktop) and `<name>-390/780` (phone), in AVIF and WebP.

## Tech stack

React 19 · TypeScript · Vite · Tailwind CSS v4 · GSAP (ScrollTrigger, SplitText) · Lenis · Vercel

## Run locally

```bash
npm install
npm run dev
```
