# Portfolio

Personal portfolio of Zain Ul Abideen, web designer and developer. Dark, editorial design with an intro counter, stacking case-study cards, scroll reveals, a magnetic cursor and smooth scrolling.

**Projects shown:** [Lumen Stay](https://lumen-stay.vercel.app) · [Glow Studio](https://glow-studio-olive.vercel.app)

## Edit your details

Everything personal is in `src/data.ts`: name, role, email, WhatsApp, GitHub, photo and the project write-ups. Put your photo in `public/` (for example `public/me.jpg`) and set `photo: '/me.jpg'`.

## Tech stack

React 19 · TypeScript · Vite · Tailwind CSS v4 · GSAP (ScrollTrigger, SplitText) · Lenis · Vercel

## Run locally

```bash
npm install
npm run dev
```
